# Data Structures Carbon Footprint System

A C++ academic group project focused on analysing transportation and carbon-emission data using two core data structures: arrays and singly linked lists.

## Project Overview

This project uses transportation datasets from three cities to analyse resident travel behaviour, carbon emissions, age groups, sorting, searching, and memory usage. The system demonstrates how different data structures affect storage, traversal, performance, and analysis in a real-world style problem.

## Features

- Array-based data structure implementation
- Singly linked list implementation
- CSV data loading and parsing
- Age group analysis
- Carbon emission summary
- Sorting by age, distance, and carbon emission
- Searching by age group, transport mode, and distance threshold
- Memory footprint comparison

## Files Included

- `arrayimplementation.cpp` — array-based implementation
- `linkedlist.cpp` — singly linked list implementation
- `resident.h` — shared resident structure
- `dataset1-cityA.csv` — City A dataset
- `dataset2-cityB.csv` — City B dataset
- `dataset3-cityC.csv` — City C dataset
